<div class="header"><div class="title">G. To find this tree, you may ask queries of the following form:</p><ul> <li> Pick a sequence of <span class="tex-font-style-bf">distinct</span> vertices $$$a_1, a_2, \ldots, a_k$$$, where $$$k \ge 1$$$. </li></ul><p>The interactor will process your sequence and return a subset of these vertices, denoted by $$$S$$$. The set $$$S$$$ is generated by the following process: </p><ul> <li> Initially, $$$S$$$ is an empty set.<p> </p></li><li> The interactor processes the vertices in the exact order they appear in your sequence, from $$$a_1$$$ to $$$a_k$$$.<p> </p></li><li> For each $$$a_i$$$, if $$$a_i$$$ <span class="tex-font-style-bf">does not</span> share an edge with any vertex that is currently in $$$S$$$, then $$$a_i$$$ is added to $$$S$$$. Otherwise, $$$a_i$$$ is ignored.<p> </p></li><li> After processing all $$$k$$$ vertices, the interactor returns the final set $$$S$$$ to you. $$$S$$$ is represented by a binary string $$$s$$$ of length $$$k$$$, where $$$s_i=\texttt{1}$$$ if and only if $$$a_i \in S$$$. </li></ul><p>Your task is to find all $$$n-1$$$ edges of the hidden tree. To make the problem harder, the sum of $$$k$$$ over all queries must not exceed $$$30 \cdot n$$$.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The description of the test cases follows.</p><p>The first line of each test case contains an integer $$$n$$$ ($$$2 \le n \le 10^3$$$), representing the number of vertices in the hidden tree.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$10^3$$$.</p></div><div><div class="section-title">Interaction</div><p>To make a query, output a line in the following format:</p><ul> <li> $$$\mathtt{?}\;k\;a_1\;a_2\;\ldots\;a_k$$$ ($$$1 \le k \le n$$$, $$$1 \le a_i \le n$$$, $$$a_i \ne a_j$$$ for all $$$1 \le i  \lt  j \le k$$$) </li></ul><p>As a response to the query, you will receive a binary string of length $$$k$$$, representing $$$S$$$. </p><p>To report the answer, first output $$$\mathtt{!}$$$ on a single line. Then, output $$$n-1$$$ lines, where the $$$i$$$-th line contains two integers $$$u_i$$$ and $$$v_i$$$, representing an undirected edge between vertices $$$u_i$$$ and $$$v_i$$$. You may output the edges in any order.</p><p>After this, proceed to the next test case or terminate if this is the last test case.</p><p>The interactor is <span class="tex-font-style-bf">not adaptive</span>. This means that the hidden tree is fixed before any queries are made and will not change throughout the interaction.</p><p>After printing each query do not forget to output the end of line and flush$$$^{\text{∗}}$$$ the output. Otherwise, you will get <span class="tex-font-style-tt">Idleness limit exceeded</span> verdict. If, at any interaction step, you read $$$-1$$$ instead of valid data, your solution must exit immediately. This means that your solution will receive <span class="tex-font-style-tt">Wrong answer</span> because of an invalid query or any other mistake.
